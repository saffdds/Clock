 Clock 🕒

Un orologio minimale e leggero scritto in *Python*.

## Cos'è?
Questo è un progetto Open Source nato per fornire un monitor temporale essenziale direttamente nel terminale. È perfetto per chi vuole tenere d'occhio l'ora e la data senza appesantire il sistema con interfacce grafiche inutili.

## Caratteristiche
- *Leggero:* Utilizza solo librerie standard di Python.
- *Cross-platform:* Funziona su Windows, Linux e macOS.
- *Minimalista:* Visualizzazione sulla stessa riga (no spam nel terminale).

## Come usarlo
Per avviare l'orologio, assicurati di avere Python installato e lancia:
```bash
python clock.py
